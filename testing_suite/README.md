Automated Testing Suite (Postman & Newman) 🧪

📌 Descripción

Conjunto de pruebas automatizadas y aserciones en JavaScript (Chai) diseñadas para auditar la integridad, disponibilidad y calidad de las respuestas de APIs RESTful.

🛠️ Conceptos Clave

Status Assertions: Validación automática de respuestas HTTP 200 OK.

Sanitización & Data Integrity: Filtrado de campos nulos o con espacios en blanco (trim() === "").

CLI Execution (Newman): Ejecución de las colecciones directamente desde la terminal del sistema operativo para integración continua.

📄 Archivos

postman_tests.js: Scripts de aserción ejecutados en la solapa Tests de Postman.

postman_collection.json: Colección exportada lista para ejecutar con Newman.
