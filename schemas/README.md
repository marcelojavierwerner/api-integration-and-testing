Schemas & Payload Design 📋

📌 Descripción

Esta carpeta contiene los modelos de datos y esquemas JSON diseñados para el intercambio de información estructurada en endpoints de la API REST.

🛠️ Conceptos Clave

Tipado e Integridad: Estructuración de datos combinando tipos primitivos (string, number, boolean) e iterables (array).

Casos de Uso Logísticos: Definición de la carga útil (payload) para seguimiento de órdenes, clientes y banderas de seguridad (Dangerous).

📄 Archivos

order_payload.json: Modelo de datos para la gestión de pedidos y artículos en tránsito.
