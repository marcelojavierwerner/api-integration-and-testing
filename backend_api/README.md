Express.js REST Backend ⚡

📌 Descripción

Módulo backend desarrollado sobre Node.js y Express.js que simula un servidor de servicios para exponer endpoints HTTP RESTful.

🛠️ Conceptos Clave

HTTP Methods & Status: Manejo de peticiones GET y retorno de códigos de estado adecuados (200 OK).

JSON Serialización: Retorno de colecciones de objetos estructuradas preparadas para consumo frontend o canal de datos.

📄 Archivos

api4.js: Servidor de aplicación en Express.

package.json: Definición de dependencias y scripts de inicio.

package-lock.json: Registro de versiones de dependencias.
